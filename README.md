# Portfólio de Estudos em Desenvolvimento Web

![Screenshot do site](TELA.png)

Este repositório reúne um projeto de estudo desenvolvido com foco em HTML, CSS e JavaScript, com o objetivo de mostrar meu progresso inicial na área de programação e desenvolvimento web.

## Sobre este projeto

Este projeto foi criado como parte da minha jornada de aprendizado, com o intuito de praticar a construção de páginas web, organização de arquivos, estruturação de conteúdo e criação de interfaces mais organizadas e visualmente agradáveis.

## O que estou aprendendo

- HTML5
- CSS3
- JavaScript básico
- Estruturação de páginas web
- Organização de projetos no GitHub
- Desenvolvimento de um portfólio profissional

## Objetivo profissional

Estou iniciando minha carreira na área de tecnologia e busco oportunidades para crescer como desenvolvedora. Este projeto representa meu primeiro passo para construir experiência prática, demonstrar meu aprendizado e fortalecer meu portfólio para futuras oportunidades de emprego.

1. Abra o arquivo index.html em seu navegador.
2. Navegue pelas páginas do site.
3. Use este repositório como referência do meu processo de estudo e evolução.
